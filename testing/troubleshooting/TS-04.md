# TS-04 — OSPF neighbor does not form

_Run 2026-11-08 22:01 UTC on the namespace emulation._

**Fault injected:** OSPF hello/dead timers on BR-R2 G0/1 changed to 5/20 (HQ-R1 uses 10/40).

## Symptom

```
$ vtysh -N hq-r1 -c show ip ospf neighbor

Neighbor ID     Pri State           Dead Time Address         Interface                        RXmtL RqstL DBsmL
2.2.2.2           1 Full/DROther       3.704s 10.0.12.2       g0-1:10.0.12.1                       0     0     0

```

## Diagnosis (show ip ospf interface)

```
$ bash -c vtysh -N hq-r1 -c 'show ip ospf interface g0-1' | grep -E 'Timer|Hello'
  Timer intervals configured, Hello 10s, Dead 40s, Wait 40s, Retransmit 5
    Hello due in 5.380s
```

```
$ bash -c vtysh -N br-r2 -c 'show ip ospf interface g0-1' | grep -E 'Timer|Hello'
  Timer intervals configured, Hello 5s, Dead 20s, Wait 20s, Retransmit 5
    Hello due in 1.351s
```

The hello and dead intervals must match on both ends of a link. With 10/40 against 5/20, hellos are discarded and the adjacency never reaches Full.

## Fix

```
$ vtysh -N hq-r1 -c show ip ospf neighbor

Neighbor ID     Pri State           Dead Time Address         Interface                        RXmtL RqstL DBsmL
2.2.2.2           1 Full/DROther       1.678s 10.0.12.2       g0-1:10.0.12.1                       0     0     0

```

## Outcome

**Root cause:** OSPF hello/dead interval mismatch on the WAN link.

**Verified after fix:** PASS
