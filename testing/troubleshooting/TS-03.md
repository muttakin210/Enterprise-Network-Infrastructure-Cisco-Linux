# TS-03 — Branch cannot reach HQ

_Run 2026-11-08 22:01 UTC on the namespace emulation._

**Fault injected:** `no network 192.168.50.0/24 area 0` on HQ-R1, so the Servers VLAN is no longer advertised.

## Symptom

```
$ ip netns exec hr-pc ping -c 2 -W 1 192.168.50.10
PING 192.168.50.10 (192.168.50.10) 56(84) bytes of data.
From 192.168.30.1 icmp_seq=1 Destination Net Unreachable
From 192.168.30.1 icmp_seq=2 Destination Net Unreachable

--- 192.168.50.10 ping statistics ---
2 packets transmitted, 0 received, +2 errors, 100% packet loss, time 1001ms

```

## Diagnosis

```
$ vtysh -N br-r2 -c show ip route 192.168.50.10
```

```
$ vtysh -N hq-r1 -c show running-config ospfd
Building configuration...

Current configuration:

BR-R2 has no route to 192.168.50.0/24 because HQ-R1 stopped advertising it. The adjacency is still Full, so this is a missing network statement, not a WAN fault.

## Fix

```
$ vtysh -N br-r2 -c show ip route 192.168.50.10
Routing entry for 192.168.50.0/24
  Known via "ospf", distance 110, metric 20, best
  Last update 00:00:02 ago
  * 10.0.12.1, via g0-1, weight 1

```

```
$ ip netns exec hr-pc ping -c 2 -W 1 192.168.50.10

## Outcome

**Root cause:** OSPF network statement for 192.168.50.0/24 missing on HQ-R1.

**Verified after fix:** PASS
