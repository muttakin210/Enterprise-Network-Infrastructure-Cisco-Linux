# TS-05 — Trunk does not carry a required VLAN

_Run 2026-11-08 22:02 UTC on the namespace emulation._

**Fault injected:** VLAN 50 removed from the HQ-SW1 → HQ-R1 trunk (`switchport trunk allowed vlan remove 50`).

## Symptom

```
$ ip netns exec it-pc ping -c 2 -W 1 192.168.50.10
PING 192.168.50.10 (192.168.50.10) 56(84) bytes of data.

--- 192.168.50.10 ping statistics ---
2 packets transmitted, 0 received, 100% packet loss, time 1008ms

```

## Diagnosis (show interfaces trunk)

```
$ bridge -n hq-sw1 vlan show dev g0-0
port              vlan-id  
g0-0              10
                  20
                  99
```

```
$ ip neigh show dev br-vlan50
192.168.50.1 lladdr 3a:7b:44:6e:d0:08 STALE
```

The trunk allows 10, 20 and 99 but not 50, so frames between the server and its gateway 192.168.50.1 are dropped at the switch.

## Fix

```
$ bridge -n hq-sw1 vlan show dev g0-0
port              vlan-id  
g0-0              10
                  20
                  50
                  99
```

```
$ ip netns exec it-pc ping -c 2 -W 1 192.168.50.10
PING 192.168.50.10 (192.168.50.10) 56(84) bytes of data.
64 bytes from 192.168.50.10: icmp_seq=1 ttl=63 time=0.472 ms
64 bytes from 192.168.50.10: icmp_seq=2 ttl=63 time=0.199 ms

--- 192.168.50.10 ping statistics ---
2 packets transmitted, 2 received, 0% packet loss, time 1020ms
rtt min/avg/max/mdev = 0.199/0.335/0.472/0.136 ms
```

## Outcome

**Root cause:** VLAN 50 pruned from the 802.1Q trunk.

**Verified after fix:** PASS
