# TS-06 — Ubuntu DNS service is unreachable

_Run 2026-11-08 22:02 UTC on the namespace emulation._

**Fault injected:** the UFW DNS rules for the lab networks are deleted.

## Symptom

```
$ ip netns exec fin-pc dig +time=2 +tries=1 srv01.corp.lab
;; communications error to 192.168.50.10#53: timed out

; <<>> DiG 9.18.39-0ubuntu0.22.04.8-Ubuntu <<>> +time=2 +tries=1 srv01.corp.lab
;; global options: +cmd
;; no servers could be reached
```

## Diagnosis

```
UNCONN 0      0         192.168.50.10:53        0.0.0.0:*    users:(("named",pid=13207,fd=35))

UNCONN 0      0             10.0.2.15:53        0.0.0.0:*    users:(("named",pid=13207,fd=32))          
UNCONN 0      0             10.0.2.15:53        0.0.0.0:*    users:(("named",pid=13207,fd=31))          
UNCONN 0      0             127.0.0.1:53        0.0.0.0:*    users:(("named",pid=13207,fd=25))          
UNCONN 0      0             127.0.0.1:53        0.0.0.0:*    users:(("named",pid=13207,fd=26))          
```

```
$ bash -c ufw status | grep -E '53|Status'
Status: active
53/udp                     ALLOW       10.0.2.0/24                # DNS
53/tcp                     ALLOW       10.0.2.0/24                # DNS
```

```
$ bash -c timeout 4 tcpdump -ni br-vlan50 -c 2 udp port 53 & sleep 1; ip netns exec fin-pc dig +time=1 +tries=1 srv01.corp.lab >/dev/null; wait
tcpdump: verbose output suppressed, use -v[v]... for full protocol decode
listening on br-vlan50, link-type EN10MB (Ethernet), snapshot length 262144 bytes

0 packets captured
0 packets received by filter
0 packets dropped by kernel
```

named is listening and queries reach br-vlan50 (tcpdump), but no reply is sent. UFW has no rule permitting 53/udp from 192.168.0.0/16, so the default-deny policy drops the queries.

## Fix

```
$ ip netns exec fin-pc dig +short srv01.corp.lab
192.168.50.10
```

## Outcome

**Root cause:** Host firewall had no rule for DNS from the lab networks.

**Verified after fix:** PASS
