# TS-09 — Ansible cannot connect to a router

_Run 2026-11-08 22:03 UTC on the namespace emulation._

**Fault injected:** SSH service on HQ-R1 stopped (like `transport input none` on the VTY lines).

## Symptom

```
$ sudo -u netadmin -H ansible -i inventory/emulation.yml HQ-R1 -m ping
HQ-R1 | UNREACHABLE! => {
    "changed": false,
    "msg": "Failed to connect to the host via ssh: ssh: connect to host 192.168.99.1 port 22: Connection refused",
    "unreachable": true
}
```

## Diagnosis

```
$ ping -c 1 -W 1 192.168.99.1
PING 192.168.99.1 (192.168.99.1) 56(84) bytes of data.
64 bytes from 192.168.99.1: icmp_seq=1 ttl=64 time=0.087 ms

--- 192.168.99.1 ping statistics ---
1 packets transmitted, 1 received, 0% packet loss, time 0ms
rtt min/avg/max/mdev = 0.087/0.087/0.087/0.000 ms
```

```
$ bash -c nc -zv -w 2 192.168.99.1 22 2>&1
nc: connect to 192.168.99.1 port 22 (tcp) failed: Connection refused
```

ICMP works but TCP/22 is refused, so it is not a routing or ACL problem: the SSH service on the device is not listening.

## Fix

```
$ sudo -u netadmin -H ansible -i inventory/emulation.yml HQ-R1 -m ping
HQ-R1 | SUCCESS => {
    "changed": false,
    "ping": "pong"
}
```

## Outcome

**Root cause:** SSH not running/allowed on the router's management address.

**Verified after fix:** PASS
